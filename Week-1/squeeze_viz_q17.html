Squeeze Q17: (1, 3, 1, 4) → (3, 4)

x17 = torch.rand(1, 3, 1, 4). squeeze removes dims whose size is 1. It never touches data, only the shape.

1. What the shape looks like

x17 1dim 03dim 1 1dim 24dim 3
x17.squeeze() 1dim 03dim 1 1dim 24dim 3 → 3dim 0 4dim 1
x17.squeeze(0) 1dim 03dim 1 1dim 24dim 3 → 3dim 0 1dim 1 4dim 2
x17.squeeze(3) 1dim 03dim 1 1dim 24dim 3 → 1 3 1 4

Red slots have size 1 and are removable. The last row is your original attempt: dim 3 has size 4, so squeeze silently returns the tensor unchanged. No error, just a no-op.

2. What the data looks like

A size-1 dim is a bracket pair with exactly one thing inside. Squeezing peels those brackets off. The 12 numbers and their order never change.

x17, shape (1, 3, 1, 4). Red brackets are the size-1 wrappers.
[ [ [[a b c d]], [[e f g h]], [[i j k l]] ] ]
x17.squeeze(), shape (3, 4). Same 12 values.
[ [a b c d], [e f g h], [i j k l] ]
Indexing before: four indices, two of which can only ever be 0.
x17[0, 1, 0, 2] = g
Indexing after: the forced-zero indices are gone.
sq17[1, 2] = g

That is the whole point: a size-1 dim carries no information, since the only valid index is 0. Removing it makes the tensor easier to index and lets it broadcast the way you expect, without moving a byte.

3. The 3 × 4 grid underneath

Both tensors read memory in the same order. Strides go from (12, 4, 4, 1) to (4, 1): the entries for the removed dims were simply dropped. The result is a view sharing storage with x17.
